Website Design System

A custom website design system built as part of the Codecademy Front-End Engineer Career Path.

Project Overview

This project demonstrates foundational HTML and CSS skills by creating a reusable visual design reference for a website.

The design system documents a consistent color palette, font families, and typography styles.

Features

Color Palette: Blue, dark gray, and light blue, with corresponding HEX codes.

Typography: Arial and Georgia font families with regular, bold, and italic variations.

Text Styles: Defined styles for main headings, subheadings, and paragraphs.

CSS Layout: Inline-block elements, spacing, and box-model styling.

Technologies Used

HTML5

CSS3

Running the Project

Clone the repository.

Open the project folder in VS Code.

Open index.html in a browser or use the Live Server extension.
